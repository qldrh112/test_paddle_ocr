발견된 주요 OCR 문제점
1. 헤더 인식 문제
✗ 모든 헤더 항목에 불필요한 공백 삽입
✗ 줄바꿈 문자가 부적절하게 삽입됨
✗ 괄호 안 번호가 잘못 인식됨 (예: 4→6, 7→0)
2. 구분자 문제
✗ '·'(중간점)을 ' - '(공백+하이픈+공백)으로 인식
✗ 쉼표(,)와 마침표(.)를 혼동
3. 날짜 형식 문제
✗ 일부 날짜의 마침표가 누락됨 (27.12.31 → 27.1231)
✗ 일부 날짜 전체가 누락됨
4. 비고 필드 문제
✗ '비고'를 '고', 'a', 'al' 등으로 오인식
✗ 빈 칸을 'a' 또는 다른 문자로 오인식
5. 금액 문제
✗ 일부 금액이 완전히 누락됨 (350,000 KRW)
✗ 천단위 구분자를 마침표로 인식 (380,204 → 380.204)
