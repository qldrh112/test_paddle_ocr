# OCR 프레임워크 비교 분석 보고서 (최종 - 서버 모델 및 크롭 포함)

## 1. 개요
본 보고서는 `paddleocr`, `easyocr`, `tesseract` 3개 프레임워크를 대상으로 **전체 페이지 방식** 및 **표 영역 정밀 크롭 방식**에서의 성능을 분석한 결과입니다. 특히 PaddleOCR의 경우 **모바일 모델**과 **서버 모델(PP-OCRv4-server)**을 각각 테스트하여 성능 변화를 확인하였습니다.

## 3. 핵심 분석

### 3.1 PaddleOCR 서버 모델 적용 결과
- **정밀도 향상**: 서버 모델(Server)을 적용했을 때 모바일 모델(Mobile) 대비 개별 단어의 인식 정확도는 확연히 개선되었습니다 (Sheet 2에서 F1 지표 상승).
- **구조적 한계**: 정밀 크롭과 서버 모델을 적용했음에도 불구하고, PaddleOCR의 기본 표 인식 모델(SLANet)이 해당 문서의 세밀한 행(Row) 구분을 수행하지 못하고 여러 행을 하나로 묶어버리는 현상이 지속되었습니다. 이로 인해 Cell-level 정확도에서는 여전히 낮은 점수를 기록했습니다.

### 3.2 최적의 프레임워크 조합
1.  **신뢰도 기반 추천**: **정밀 크롭 + EasyOCR**
    - 가장 깔끔한 데이터를 생성하며 오인식이 적습니다.
    - 정점: Precision이 매우 높음 (0.70 이상).
2.  **데이터 보존 기반 추천**: **정밀 크롭 + Tesseract**
    - 표 영역 내 거의 모든 텍스트를 가장 정확하게(Exact Match 117개) 읽어냅니다.
    - 단점: 여전히 특수문자나 띄어쓰기 등의 노이즈가 섞여 있어 후처리가 필요합니다.

## 4. 최종 결론
이번 벤치마크를 통해 **표 영역 정밀 크롭(Cropping)**이 OCR 정확도 향상의 가장 중요한 변수임을 확인했습니다. 

- **PaddleOCR**은 서버 모델 업그레이드를 통해 인식률은 개선되었으나, 표의 **구조(Structure)**를 재구성하는 로직에서 추가적인 튜닝이 필요합니다.
- **EasyOCR**과 **Tesseract**는 크롭된 이미지를 입력받았을 때 좌표 기반 클러스터링만으로도 매우 우수한 성능을 보여주었습니다.

따라서 현시점에서 해당 금융 문서 표 추출 프로젝트에 가장 적합한 아키텍처는 **[PaddleOCR Layout을 이용한 표 감지/크롭] -> [EasyOCR/Tesseract를 이용한 데이터 추출]** 조합으로 판단됩니다.
