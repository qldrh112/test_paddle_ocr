# OCR 프레임워크 대안 및 기술 동향 분석

현재 프로젝트에서 사용 중인 PaddleOCR, EasyOCR, Tesseract 외에 추가로 검토하거나 향후 확장 가능한 대안 기술들에 대한 조사 결과입니다.

## 1. PaddlePaddle 생태계 내의 상위 모델
현재 고정된 V2 모델 외에 아래 모델들로의 업그레이드를 고려할 수 있습니다.
- **PP-StructureV3**: V2 대비 표 구조 인식 정밀도가 약 9% 이상 향상되었습니다. 모델 교체만으로 성능 체감이 가능합니다.
- **PaddleOCR-VL (멀티모달)**: Vision-Language 모델로, 정형화되지 않은 복잡한 문서(스캔 노이즈가 심하거나 휘어진 문서)에서 압도적인 정확도를 보입니다.

## 2. 최신 오픈소스 트렌드 (VLM & Layout 중심)
최근 OCR 기술은 단순히 글자를 읽는 것에서 문서 전체의 구조(Context)를 이해하는 방향으로 진화하고 있습니다.

### 2.1 Surya & Marker
- **Surya**: 텍스트 라인 감지 및 표 인식이 매우 정교하며, 특히 행/열의 경계가 모호한 표에서 강력한 성능을 발휘합니다.
- **Marker**: Surya 엔진을 기반으로 PDF/이미지를 구조화된 Markdown으로 변환해줍니다. 현재 프로젝트의 "표 추출" 목적과 매우 잘 부합합니다.

### 2.2 Nougat (by Meta)
- 학술지나 보고서 형태의 문서 분석에 특화되어 있으며, 표 데이터를 Markdown 형식으로 완벽하게 재구성해주는 강점이 있습니다.

## 3. 요약 및 권장사항
현재 프로젝트는 **표 영역 크롭(Preprocessing) + EasyOCR** 조합으로 실용적인 수준의 성능(F1 0.77)을 확보했습니다. 여기서 한 단계 더 나아가려면 아래의 시도를 권장합니다:

1.  **VLM(Vision-Language Model) 도입**: 표의 선이 없거나 복잡한 병합 셀이 많은 경우 PaddleOCR-VL과 같은 멀티모달 모델 테스트가 필요합니다.
2.  **Surya 엔진 테스트**: 현재 EasyOCR의 행 그룹화 로직보다 더 정밀한 행/열 분리가 필요할 때 대안으로 가장 적합합니다.

본 프로젝트의 `scripts/` 및 `docs/Walkthrough.md`는 이러한 대안들을 평가하기 위한 기준점(Baseline)으로 활용될 수 있습니다.
