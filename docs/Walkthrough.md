# OCR 벤치마크 테스트 최종 보고서 (종합)

금융거래조회서 이미지(표)를 대상으로 PaddleOCR, EasyOCR, Tesseract의 성능을 정밀 비교 분석한 최종 결과 보고서입니다.

## 1. 테스트 개요
- **대상 샘플**: 3, 4, 6, 9번 이미지 (테이블 집중 샘플, `public/image/tables/` 위치)
- **정답 레이블**: `public/label/sheet1, 2, 5, 9_label.csv`
- **테이블 크롭 전처리**: PaddleOCR Layout을 활용하여 표 영역만 격리 후 테스트 진행

| 이미지 / 레이블 | 프레임워크 | 크롭 이미지 (F1) | 원본 이미지 (F1) | 개선율 |

> [!NOTE]
> - **EasyOCR**이 모든 지표에서 가장 안정적이고 높은 성능을 보여주었습니다.
> - **PaddleOCR**은 현재 이미지 스타일에서 표 구조 추출에 어려움을 겪고 있으나, 크롭 후 일부 매칭이 시작되는 개선을 보였습니다.

## 3. 핵심 성공 요인: 이미지 전처리 (Cropping)
표 영역만 사전에 추출하여 OCR을 수행했을 때 인식률이 비약적으로 상승했습니다.
- **노이즈 제거**: 본문 텍스트나 도장 등 표 외부 요소에 의한 간섭 차단
- **구조 집중**: OCR 엔진이 표의 셀 구조를 인식하는 데 훨씬 유리한 환경 제공

## 4. 프레임워크별 분석 요약

### 🥇 EasyOCR (추천)
- **장점**: 한국어 및 숫자 인식 능력이 가장 뛰어남. 복잡한 표에서도 행 분리가 안정적임.
- **특징**: PyTorch 기반으로 GPU 가속 시 매우 빠른 속도 제공.

### 🥈 Tesseract
- **장점**: 텍스트를 많이 잡아내는 능력(Recall)이 좋음. 표 영역만 잘려 있을 때 성능이 극대화됨.
- **단점**: 원본 이미지에서는 오인식이 많아 Precision이 낮음.

### 🥉 PaddleOCR
- **장점**: Layout 분석 도구(`preprocess_crops.py`)로서의 가치가 매우 높음.
- **단점**: 현재 금융 문서 이미지의 미세한 선(line) 인식이 다른 도구에 비해 보수적임.

## 5. 향후 권장 워크플로우
최상의 결과를 얻기 위한 권장 프로세스는 다음과 같습니다:
1. **Layout Detection**: `PaddleOCR`을 사용하여 표 영역을 감지하고 크롭합니다.
2. **Main OCR**: 크롭된 표 이미지를 `EasyOCR`로 분석하여 텍스트 데이터화합니다.
3. **Accuracy Monitoring**: `scripts/compare_results.py`를 통해 주기적으로 품질을 관리합니다.
